## Installation Instructions

### macOS Users (Important!)
As a beta application, macOS will show a security warning. This is normal for un-notarized software. Follow these steps:

1. **Download** the .DMG file for your Mac type
2. **Drag** Bouquine to your Applications folder
3. **Right-click** the app icon and select **Open**
4. Click **Open** on the security warning
5. If you don't see the option, go to:
   - System Settings → Privacy & Security → Security
   - Look for "Bouquine was blocked..."
   - Click **Open Anyway**

### Windows Users
1. Download the .exe file
2. Run the installer
3. Launch from Start Menu or Desktop shortcut

### Linux Users
1. Download the .AppImage file
2. Make executable: `chmod +x Bouquine-linux.AppImage`
3. Run: `./Bouquine-linux.AppImage`
